# QECTOR Quantum Error Correction Extension for Claude Desktop

Grounded in the QECTOR Reference Manual v1.0.0 (DOI: 10.5281/zenodo.21941046).

## Features
- Mathematically verified quantum syndrome decoding ($H c \equiv s \pmod 2$).
- Wilson 95% binomial score confidence intervals for threshold sweeps.
- 10 quantum code families: Surface, Toric, Color, Heavy-Hex, and qLDPC.
- 100% offline bare-metal execution with zero cloud egress.
