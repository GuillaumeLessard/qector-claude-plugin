# Production runtime for the library-first Claude MCP server.
# Supports CPython 3.9-3.13. numpy is declared as a version RANGE, not an
# exact pin, matching qector-decoder-v3==1.0.0's own published constraint
# (numpy>=1.24.0,<2.3, verified against the installed wheel's metadata).
# numpy itself has no single release spanning 3.9-3.13 (1.26.x is the last
# to support 3.9; numpy 2.1+ drops 3.9 and requires 3.10+), so a range is
# required for pip to resolve a working wheel per interpreter, and the
# range must stay inside qector-decoder-v3's own bound or pip's resolver
# will fail rather than silently pick something incompatible.
numpy>=1.26,<2.3
qector-decoder-v3==1.0.0
# mcp>=1.28.1 fixes three high-severity GitHub Security Advisories against
# the v1.x line (WebSocket transport Host/Origin validation, HTTP transport
# session-request auth bypass, experimental task-handler cross-client
# cancellation): GHSA-hvrp-rf83-w775 / CVE-2026-52870, GHSA-jpw9-pfvf-9f58 /
# CVE-2026-52869, GHSA-vj7q-gjh5-988w / CVE-2026-59950. mcp 2.0.0 (stable,
# released 2026-07-28) is a breaking major rework -- FastMCP renamed to
# MCPServer, McpError renamed to MCPError, mcp.types split into a separate
# package, and the WebSocket transport removed outright -- and this
# codebase imports mcp.types directly (see mcp/mcp_server_library.py), so
# the <2 upper bound is required to stay on the patched v1.x line rather
# than silently resolving to the incompatible v2 release.
mcp>=1.28.1,<2
# Keep the installed pyOpenSSL ecosystem compatible with the wheel requirement.
cryptography>=48.0.1,<50
